# KSP Спутник-5

Моделирование полёта Спутник-5 в Kerbal Space Program. Математическая модель на Python, управление через kRPC.

## Требования
- Kerbal Space Program 1.12.3
- Моды: kRPC, Kerbal Engineer Redux (опционально)
- Python 3.10+

## Структура
- `model/` математическая модель - математик
- `autopilot/` kRPC-скрипты - программист
- `rocket/` ракета, параметры, сохранения - физик-сборщик
- `data/` телеметрия - программист
- `analysis/` графики - математик
- `report/` отчёт и презентация
- `docs/` заметки
